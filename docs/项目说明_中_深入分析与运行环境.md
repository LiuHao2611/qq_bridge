# 第三批 · 深入分析资料

## C1 SQLite 库结构与迁移
- **实际库文件位置**（清单要求项）：`server/app.db`（主库，约 520KB）、`data/manju_app.db`（运行时快照，路径受 `MANJU_DB_PATH` 控制）；`server/app_verify.db` 与 `server/_writetest.db` 为校验/写入测试副产物，**非业务库**，可忽略。无独立 `schema.sql` 静态文件，schema 由 `db.py` 的 `_migrate()` 在建库时以 ALTER 动态补齐（见 A2）
- 迁移脚本 `_migrate()` 以 ALTER 补齐历史库字段，幂等（列已存在忽略）；`asset_poses`/`memoir_fact_anchors`/`feedbacks` 带级联删除；`module_versions/module_flags` 支撑模块灰度
- 生命周期：中间帧/尾帧参考图保留 7 天（`infra/storage` `INTERMEDIATE_TTL_DAYS=7`，OPS-02 已对齐）

## C2 接口契约（OpenAPI / Swagger）
- 信封固定 `{code,data,message,request_id,timestamp}`，`code=0` 成功；错误用 `ApiError(name)`
- 列表返回 `{items, pagination:{page,page_size,total,total_pages,has_next,has_prev}}`
- **自动 OpenAPI**：FastAPI 自带 `/docs`（Swagger）与 `/openapi.json`（运行期生成，仓库无静态 `openapi.json`）；根目录另有 `openapi_dify.yaml`（Dify 集成用，非平台主 API）
- **关键端点族**：`/user/* /points/pre-auth /projects[/:id/...] /segments /shots /assets[/:id/...] /stages /poses /face-vector /tasks[/:id] /memoirs[/:id/...] /feedback /templates /settings /models/test /synthesize /director-run /t2i /i2i /logs /system/* /modules/* /ws`
- 详见 A4（Director 一站式入口）与 P4（Webhook/生产视图端点）

## C3 ComfyUI workflow 与 AI 调用
- Workflow 文件驻留在秋叶 ComfyUI（`D:\AI\ComfyUI-aki-v3.2\ComfyUI\user\...`，**不在本仓库**——属"用户未提供"项，非遗漏）；后端经 `COMFY_URL=:8188` 的 `/system_stats /object_info /upload/image /history` 交互
- 视频生成节点族可探测：Wan / Seedance / LTX / HunyuanVideo / **CogVideoX** / Mochi（评估中的 CogVideoX-2B 可作为 P4 测试模型接入点，见文件（下）· 项目背景说明）
- 真实出图依赖权重：`Realistic_Vision SD1.5` 底模 + `ip-adapter_sd15` + `CLIP-ViT-H` + `buffalo_l`（512维）+ `GFPGAN/CodeFormer` + ControlNet（详见仓库根 `权重下载清单.md`）

## C4 AI Prompt 模板（§9）
- `build_prompt` 四段骨架：`role`（角色定位）/ `objective`（具体任务）/ `constraints`（软约束）/ `invariants`（硬不变量，如保留 `<ref>`、不虚构未提供事实）

# 部署 / 硬件基线（新增 · 填补 GPU 配置空白）

> 目的：原运行环境未定义最低/推荐 GPU 配置，此处基于仓库端口、环境变量与图像/视频管线事实，给出可落地的部署基线。**标注「建议值」的项需你在目标机型上实测确认。**

## 1. 服务与端口
| 服务 | 端口 | 说明 |
|---|---|---|
| 后端 API | `127.0.0.1:7788` | 纯 FastAPI，不对外 |
| 前端 + 反代 | `0.0.0.0:8099` | `web_app.py` 托管 `MANJU_FRONTEND_DIR` 并反代 `/api/v1` |
| ComfyUI | `:8188` | 秋叶 ComfyUI，`COMFY_URL` 可配 |
| Ollama | `:11434` | 本地大模型，模型 `MANJU_OLLAMA_MODEL` 可配 |
| WebSocket | `/ws` | 实时进度/日志/积分推送（§18） |

## 2. 关键环境变量
- `MANJU_DB_PATH`：SQLite 主库路径（破解工作区只读锁，指向工作区外可写副本）
- `MANJU_LOG_DIR`：日志目录
- `MANJU_FRONTEND_DIR`：前端构建产物目录（被 `web_app.py` 托管）
- `MANJU_OLLAMA_MODEL`：默认 Ollama 模型（默认 `qwen3.5:9b`）
- `MANJU_VIDEO_TIMEOUT`：视频生成超时秒（默认 `600`，与 30min 看门狗兜底）
- `COMFY_URL`：ComfyUI 地址（默认 `http://127.0.0.1:8188`）

## 3. 硬件基线（建议值）
| 档位 | GPU 显存 | 适用场景 |
|---|---|---|
| **最低（图像流水线）** | ≥4GB | SD1.5 文生图 + IP-Adapter 锁脸 + 润色；1660Ti(6GB) 可跑图像 |
| **推荐（含视频测试）** | ≥12GB | 可接入 CogVideoX-2B / Wan2.1-1.3B / LTX 等轻量视频模型做功能验证 |
| **理想（质量/分辨率）** | ≥16–24GB | 视频模型开更高分辨率/更长片段，或 5B 级模型 |

- **CPU**：4 核以上；**内存**：≥16GB（视频生成时权重常驻）
- **磁盘**：SSD，预留 ≥60GB（SD1.5 权重 ~5GB + 视频模型权重 数十GB + 中间帧/成片）
- **系统**：Windows（已验证 win32）；Python venv + Node 前端构建

## 4. 外部依赖前置
- 秋叶 ComfyUI（含 IP-Adapter + CLIP-ViT）已部署并可访问 `:8188`
- Ollama 已拉起并装有 `qwen3.5:9b`（或指定模型）
- FFmpeg 在 `PATH` 或可经 `D:\AI\tools\ffmpeg` 调用
- 视频测试模型权重（如 CogVideoX-2B）按需下载至 ComfyUI `models/` 对应目录

## 5. 启动顺序
`init_db()` → `reconcile_points()`（资金对账）→ `worker_start()`（含崩溃恢复）→ `web_app.py` 反代启动
