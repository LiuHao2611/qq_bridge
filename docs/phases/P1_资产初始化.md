# P1 · 资产初始化（冷启动）

> 阶段定位：项目中心流程第 1 阶段。KB 依据《万能短剧AI创作平台-开发手册》§04 §4.4.1（角色多阶段 + 多姿势）与全集/本集隔离复用。
> 关联索引：见根目录 `PROJECT_MAP.md` → 文档索引 · 阶段原子模块。

## 一、需求（KB 对齐）
- 角色支持「年龄阶段（童年/少年/青年/中年/老年）+ 多姿势（front/side/back/full_body/custom）」。
- 全集（全局）资产库与本项目（本集）资产库隔离复用：本集可一键复用全集角色/场景/道具。

## 二、已实现
- **数据**：`server/db.py` 迁移新增 `asset_poses` 表（姿势，级联删除）+ 索引；`assets` 表 `is_global` 区分全集/本集。
- **接口**（`server/routers.py`）：
  - `POST /upload-image`：通用参考图上传，返回 `/file?name=` 可直接作 `<img>` src（阶段/姿势参考照）。
  - `GET /assets/{id}/stages-with-poses`：返回角色年龄阶段及其内嵌姿势列表。
  - `POST /asset-stages/{stage_id}/poses`、`DELETE /asset-stages/{stage_id}/poses/{pose_id}`：姿势 CRUD。
  - `POST /asset-hub/roles/{id}/import`：角色从全集复用至本集（含 asset_stages + face_vector 深拷贝、`_import_global_role_asset` 同名幂等）。
- **前端**：`src/components/Assets.vue` 角色卡片展开「阶段/姿势」面板；`src/api.js` 新增 `uploadImage / listStagesWithPoses / addStage / delStage / addPose / delPose / importRole`。

## 三、隔离契约
- `GET /assets` 按设计返回**全部**资产；前端全局页按 `is_global !== 0` 过滤，本集页显示 `is_global === 0`。
- `current_phase=1` 判定：本集（`is_global=0`）资产数 > 0。
- 全局资产库 `/global-assets`（顶层全局页）与项目内「资产初始化」页 `/projects/:id/assets` 是两回事，流程步骤不得指向全局页（见 `UI_NAV_SPEC.md` §6）。
