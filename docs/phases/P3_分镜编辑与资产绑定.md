# P3 · 多模态分镜编排与资产绑定

> 阶段定位：项目中心流程第 3 阶段。KB 依据《万能短剧AI创作平台-开发手册》业务模块「富文本→JSON + LLM 润色 + IP-Adapter/ControlNet 三股流」+ 资产绑定。
> 关联索引：见根目录 `PROJECT_MAP.md` → 文档索引 · 阶段原子模块。

## 一、需求（KB 对齐）
- 分镜编辑器：富文本分镜描述 ↔ 结构化 JSON；LLM 提示词润色；IP-Adapter / ControlNet 三股流（角色/场景/动作）。
- 资产绑定：在分镜内 `@` 提及引用 P1 管理的角色/场景/道具（含阶段/姿势）。

## 二、已实现（核验已对齐，2026-08-07 新增资产拖拽引用）
- **前端**：`src/components/ProjectFragmentEditor.vue` 三栏编辑器（分镜卡 / 提示词 / 预览），`@` 提及 → 资产引用 chip。
  - 实时同步：新增 `@update:modelValue` 触发 `syncMentionRefs`（修正 Playwright `.fill()` 不触发失焦导致引用不同步）。
  - 反向提示词 / 镜头设定：`shots.negative_prompt` / `shots.setting` 输入与回读。
  - `onSyncAll` 跳转改为 `/projects/:id/production`（P4）。
  - **资产拖拽引用（KB §5.3.4 / §04 / §05）**：左栏资产卡片 `draggable`，`dragstart` 写入 `dataTransfer`（asset_id/name/kind）；分镜文本域（画面描述 / 画外音 / 对白 / 提示词 prompt / 镜头设定 setting）接受 `drop`，在**光标处插入 `@[资产名]`** 标记并同步 `shot.refs`（BR-009 段级 ≤9 守卫）；`syncMentionRefs` 正则同时兼容手动 `@资产名` 与拖拽 `@[资产名]`。拖拽悬停高亮反馈。
- **后端**（`server/routers.py` · `put_shots`）：`REDUN-03` 冗余对账——以资产库（项目资产 + 全局资产）`name→id` 为单一真相，从分镜文本抽取 `@[名]`/`@名` 引用并与客户端 `asset_refs` 去重合并回写；`BR-009` 服务端兜底（片段唯一引用 >9 抛 `MAX_REFS_EXCEEDED`）。抽取逻辑收敛为模块级 `_reconcile_segment_refs`。
- **组合式**：`src/composables/useProject.js` 抽出 `applyActiveSegment` / `switchSegment` / `addSegment` / `removeSegment` / `applyAssets` / `refreshAssets`。
- **接口**（`server/routers.py`）：`patch_chapter`、`put_shots`（写入 negative_prompt/setting + REDUN-03 引用对账）、`create_segment` / `delete_segment`、`getProject` 回读资产。
- **API**（`src/api.js`）：`getProject / patchChapter / putShots / createSegment / deleteSegment / createAsset / getTask`。

## 三、阶段判定
- `current_phase=3`：存在状态 ≠ `draft` 的片段。
- `current_phase=4`：存在 `succeeded` 片段 且 无待生成片段。
