# P5 · 多片段音视频合成导出

> 阶段定位：项目中心流程第 5 阶段（终态）。KB 依据《万能短剧AI创作平台-开发手册》业务模块「TTS 旁白 + BGM + FFmpeg 拼接 + 字幕 + 归档」。
> 关联索引：见根目录 `PROJECT_MAP.md` → 文档索引 · 阶段原子模块。

## 一、需求（KB 对齐）
- 将各分镜生成视频按序拼接为成片；可选叠加 TTS 中文旁白、BGM 混流、硬字幕烧录；产出可下载 MP4 并归档。

## 二、已实现
- **`server/ai_local.py`** 重写 `synthesize_project_video`：基础拼接保留；按选项叠加——
  - `tts`：收集各片段 `shots.voiceover/dialogue` 作旁白，TTS 生成音轨（优先 `edge-tts` → `pyttsx3`，均缺失则跳过）。
  - `bgm`：循环铺底并与旁白 `amix` 混流（`bgm_path` 指向合法音频）。
  - `subtitle`：由各片段对话生成 SRT 并烧录硬字幕（失败降级跳过）。
  - 全程 `try/except` 优雅降级，任一后期失败不阻断主流程；结束统一释放临时文件。
- **`server/worker.py`** — `synthesize` 分支透传前端选项（`tts`/`bgm`/`subtitle`）给 `ai_local`；`generate`/`synthesize` 提交写 `trace_id` 贯穿任务↔日志。
- **`server/routers.py`** — `synthesizeProject`（前端 `src/api.js`）触发合成；`GET /file` 回传成片。

## 三、阶段判定

## 四、§08 纪律落点
| 规则 | 落点 |

| REDUN-01 降级链 | TTS/BGM/字幕依赖缺失时跳过并继续（不阻断） |

## 五、验证
- 单元测试（真实 ffmpeg 拼接）：开启 `subtitle` 成功烧录（产出 51KB MP4）；`tts` 因无 `edge-tts`/`pyttsx3` 优雅跳过，符合 REDUN-01；产出文件有效。
- 后端 E2E `tests/pipeline_e2e.mjs` Phase5 合成通过。

## 六、残留 / 后续
- **TTS 依赖可选**：安装 `edge-tts`（在线）或 `pyttsx3`（离线）后合成自动叠中文旁白。
- **BGM 需提供路径**：`bgm_path` 指向合法音频即混流；未提供则仅旁白/视频。
