# P2 · 项目策划与分场拆解

> 阶段定位：项目中心流程第 2 阶段。KB 依据《万能短剧AI创作平台-开发手册》业务模块「LLM 拆场次 + 识别角色/场景 + 空分镜表」。
> 关联索引：见根目录 `PROJECT_MAP.md` → 文档索引 · 阶段原子模块。

## 一、需求（KB 对齐）
- 用户输入故事/梗概 → LLM 自动拆解分场；识别涉及角色/场景；产出空分镜表供后续编排。

## 二、已实现（核验已对齐，本轮无实质改动）
- **前端**：`src/components/ProjectPlanning.vue` 对接 `split-story`（LLM 拆解）+ `createSegment`（建空分镜）+ 角色标签识别。
- **接口**（`server/routers.py`）：`split-story`、`createSegment`（时长均分）、`get_project` 派生 `current_phase`。

## 三、阶段判定
- `current_phase=2`：存在 `scene_description` 非空的片段。
- `current_phase=3`：存在状态 ≠ `draft` 的片段。
- 项目统一入口 `/projects/:id`（`src/components/ProjectEntry.vue`）按 `current_phase` 自动跳转，禁止写死阶段落点。
