# 第五批 · 项目背景说明

> 本批对应原清单「商业背景」类目。本项目为**个人本地自用的 AI 短剧创作工具**，不涉及商业运营、对外分发或盈利，因此原类目中的「竞品分析」「商业规划」两项对本项目不适用；以下仅从代码与文档反推给出项目背景与用途说明，供第三方理解与部署参考。

- **项目用途**：在本地环境完成短剧从创意到成片的自动化制作——建项目、初始化角色/场景资产、AI 分场拆解、分镜编排、异步生成、音视频合成导出；另含「人生回忆录」子系统（memoir）。
- **目标使用者**：个人用户（单机本地运行，数据不出本机、无需云端账号）。
- **使用流程**：建项目 → P1 资产初始化（上传/一键提取）→ P2 分场拆解（AI/正则）→ P3 分镜编排（@提及绑定资产）→ P4 异步生成（积分预授权→队列→轮询）→ P5 合成导出；回忆录为相对独立的子流程。
- **功能范围（代码侧印证）**：五阶段主线 > Director 一站式编排 > 回忆录 > 模块灰度管理器 > 反馈/模板/资产库。
- **不适用项说明**：原类目「竞品分析」「商业规划」属商业运营范畴，本项目为个人自用、无对外运营，故不适用，不在文档中展开。
