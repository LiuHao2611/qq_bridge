## 〇、纠正说明（为什么"重做"）

用户明确指出：**第四阶段不是「任务中心」，而是「任务分发与异步 AI 推理（生产阶段）」**。

原实现把 P4 错误地实现成一个"任务列表页 / 任务中心"（独立的 `/tasks` 路由、导航第四步标「任务中心」）。这与 KB 的定位冲突：

- KB 的流水线阶段是：**资产库 → 分镜编辑 → AI 视频生成（§05-v2 模块五）→ 视频预览 → 合成导出**。
- KB §18（WebSocket）/ §06（Webhook 回调）定义的是**生产阶段的实时链路**：把生成任务分发给 AI 推理引擎、并以 WebSocket 实时回传进度/日志/完成事件；外部异步推理引擎通过 Webhook 回调落地结果。
- KB 路由树中**不存在独立的"任务中心"页面**——任务是跨切面的概念，应内嵌在编辑器 / 生产视图中呈现，而非单列一个流程阶段页。

本轮按 KB 规范**重做 P4**：把"任务中心"页面降格为跨切面诊断视图（改名为「推理监控」），新增真正的**「生成生产」阶段页（ProductionStage）**，并补齐 §18 WebSocket 实时网关 + §06 异步 Webhook 回传的完整后端链路。

