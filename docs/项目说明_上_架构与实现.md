# 第一批 · 核心项目模型

## A0 项目定位
- **名称**：万能短剧 AI 创作平台（个人本地版 · `personal_local_only`），代码名 `manju_agent`
- **一句话**：面向个人短剧创作的本地 AI 视频创作工具，五阶段流水线 + 导演调度 Agent 编排层
- **设计边界**：纯本地运行，不依赖任何云端 Key 或外部付费 API；AI 能力由本地 Ollama + 秋叶 ComfyUI + FFmpeg 提供，面向通用 GPU 环境部署（以本地方案替代云端模型能力）
- **运行时端口**：后端 `127.0.0.1:7788`（纯 API）；前端 `web_app.py` 托管 `MANJU_FRONTEND_DIR` 并反代 `/api/v1` 于 `0.0.0.0:8099`；外部 ComfyUI `:8188`、Ollama `:11434`

## A1 最高约束规则（AGENTS.md / KB 第 8 章）
规则冲突裁决 **MUST > SHOULD**，资金类 **CLOSE-04 最高优先级**：
- **CLOSE-01 闭环**：写操作必有终态；任务状态机 `queued→running→succeeded/failed`（failed 可 `retrying`）；Worker 启动 `recover()` 复位崩溃遗留 `running→queued`；看门狗 >30min 回收卡死
- **CLOSE-02 幂等**：积分预授权 `idempotency_key` 去重；生成提交同 `pre_auth_id` 活跃任务直接返回；禁用 `Date.now()+random()` 作幂等键
- **CLOSE-03 日志/重试/原子性**：请求中间件带 `x-request-id`；出站调用指数退避重试(≤3)；生成失败退避重试(≤2)；写操作记 `operation_logs`；**禁静默吞错**
- **CLOSE-04 资金安全**：提交前必须 pre-auth（冻结即真实扣减）；失败/超上限最终 `failed` 退冻结金；启动 `reconcile_points()` 防误退膨胀
- **§9 提示词纪律**：所有本地大模型提示词须经 `ai_local.build_prompt(role, objective, constraints, invariants)`，禁止散写裸字符串
- **不可变不变量**：信封 `{code,data,message,request_id,timestamp}`；列表返回 `{items, pagination}`；分镜枚举单一来源 `src/mock.js`（`shot_type/camera_movement/camera_angle/focal_length`）；`camera_movement` 字段名（非 `camera_move`

## A2 数据模型（server/db.py）
- **存储**：本地 SQLite（`MANJU_DB_PATH` 优先 → 否则 `C:/Users/L/AppData/Local/Temp/manju_app_snapshot.db` 快照 → 回退 `server/app.db`）；单用户 `SINGLE_USER_ID`，积分默认 `1999995162`
- **核心表**：`users / projects / segments / shots / assets / asset_stages / segment_asset_refs / generation_tasks / generation_logs / point_transactions / messages / operation_logs / settings / templates / memoirs / memoir_chapters`
- **迁移补齐的表**：`memoir_tasks`（回忆录任务，与 segment 任务解耦）、`image_tasks`（文生图队列）、`asset_poses`（角色多姿势）、`memoir_fact_anchors`（事实锚点）、`feedbacks`（用户反馈）、`module_versions / module_flags`（模块灰度开关）
- **关键字段演进**：`generation_tasks` 增 `trace_id / progress / external_id / last_frame_path / next_attempt_at`（首尾帧锚定、看门狗、断点续跑）；`shots` 增 `image_prompt / negative_prompt / setting / stage_blueprint`；`memoirs` 增 `character_anchors / model_config` 等；`projects` 增 `first_frame_mode`

## A3 后端入口与编排（server/main.py + worker/points_engine/realtime）
- `main.py`：FastAPI `title=万能短剧 AI 创作平台·本地服务 v1.4-agent`；挂载 `routers.api` + `memoir_routes.api`；`/ws` 实时推送网关；`request_logging_middleware` 绑定 request_id；`ApiError`/未捕获异常统一写 `operation_logs` 并返回信封；`/file` 防目录穿越
- 启动 `on_startup`：`init_db()` → `reconcile_points()`（CLOSE-04 对账）→ `worker_start()`（含 CLOSE-01 崩溃恢复）
- **worker**：单进程消费 `generation_tasks`，`_serve_one` 失败退避重试(≤2)保留冻结金，超上限 `failed` 并退款；`_safe_run` 兜底标记失败
- **points_engine**：`pre_auth/settle/refund` 保证不重扣、不泄漏
- **realtime**：WebSocket 频道推送（任务/视频/通知/积分 + `director:<pid>`）

## A4 API 实现（server/routers.py 门面 + Director 一站式入口）
- 门面策略：从 `_vendor/routers_compiled.cpython-313.pyc` 载入**已验证权威实现**，再 `from routers_compiled import *` 复用全部 90+ 端点；仅对确需改的端点（如 `split_story`、`/settings`、`/models/test`、`extract-assets`、`assets/batch`）做定点覆盖
- **Director 一站式入口**（N01→N09 全链路）：`POST /projects/{id}/director-run`（后台线程跑 `GlobalScheduler.run`，返回 `run_id/trace_id`）+ `GET /director-run`（列表）+ `GET /director-run/{run_id}`（查询）；进度经 WS `director:<pid>` 推送
- **真人资产 512 维身份向量**：`GET /assets/{id}/face-vectors`、`GET/POST .../face-vector[/extract]`；缺引擎/无脸 → 诚实抛 `FeatureUnavailable`，不静默跳过锁脸
- 其余端点见 **文件（中）· C2（接口契约）**

## A5 AI 调用链路（server/ai_local.py）
- **三级离线降级**（手册·离线 AI 降级设计）：L1 本地 ComfyUI+Ollama → 真实文生图+大模型润色；L2 仅 Ollama → 润色+占位图；L3 均不可用 → FFmpeg 生成可读标题卡 mp4（保证端到端可用）
- `build_prompt(role, objective, constraints, invariants)`：四段式（角色/任务/约束/不可变），§9 纪律统一入口
- 出站 `_http_post_json` 指数退避重试(≤3, 2^n s)；`detect_comfy_video` 探测 Wan/Seedance/LTX/HunyuanVideo/**CogVideoX**/Mochi 等视频节点
- 512 维人脸向量：`features.extract_face_vector`（insightface+buffalo_l）；首尾帧锚定：`_extract_last_frame` 用 ffmpeg 抽尾帧
- 音画同步硬约束 `AUDIO_ALIGN_MAX_MS=100`（手册 §3.4.4）
- 权重自动发现 `comfy_env.discover_weight`（checkpoints/ipadapter/clip_vision/controlnet），缺权重时**诚实报错指明放哪个目录**

## A6 阶段文档索引与摘要（docs/phases/）
> 七篇阶段原子模块已逐篇精读，以下为每篇要点（细节见原文）。

### P1 资产初始化（冷启动）
角色支持「年龄阶段（童年/少年/青年/中年/老年）+ 多姿势（front/side/back/full_body/custom）」；全集（全局）资产库与本集（项目）资产库隔离复用，本集可一键复用全集角色。新增 `asset_poses` 表；接口 `upload-image`、`stages-with-poses`、姿势 CRUD、`asset-hub/roles/{id}/import`（深拷贝 face_vector，同名幂等）。纪律落点：REDUN-03 入参校验、CLOSE-03 复用幂等。

### P2 项目策划与分场拆解
用户输入故事/梗概 → LLM 自动拆解分场、识别角色/场景、产出空分镜表。前端 `ProjectPlanning.vue` 对接 `split-story`+`createSegment`（时长均分）；`current_phase=2` 判定（存在 `scene_description` 非空片段）。本轮核验无实质改动。

### P3 多模态分镜编排与资产绑定
三栏编辑器（分镜卡/提示词/预览），富文本 ↔ JSON，LLM 润色，IP-Adapter/ControlNet 三股流（角色/场景/动作）；分镜内 `@` 提及或**拖拽**引用 P1 资产（含阶段/姿势）。`put_shots` 做 REDUN-03 冗余对账（从文本抽取 `@引用` 与客户端 `asset_refs` 去重合并回写）；BR-009 段级 ≤9 引用服务端兜底守卫。纪律：JSON 脏数据防御性不崩溃（CLOSE-02）、引用闭环一致（CLOSE-01）。

### P4 任务分发与异步 AI 推理（生产阶段）
**纠正**：第四阶段**不是「任务中心」**，而是「生产阶段」；原 `/tasks` 页降格为跨切面诊断视图「推理监控」。新增 `realtime.py`（§18 WS 网关：token 鉴权、`task:{id}`/`video:{genId}`/`notifications`/`credits` 频道、心跳 ping30/pong60）；`POST /callbacks/inference`（§06 Webhook：状态映射 + CLOSE-04 失败退款）、`GET /inference/health`、`GET /projects/{id}/production`（含 `latest_task`，无 `task_center`）；前端 `ws.js`+`ProductionStage.vue` 逐段实时监看（WS 优先、轮询兜底 REDUN-01）。纪律：CLOSE-01 收敛、CLOSE-03 幂等重订阅、CLOSE-04 退款。

### P5 多片段音视频合成导出（终态）
`synthesize_project_video` 按选项叠加 TTS 旁白（`edge-tts`→`pyttsx3`）、BGM 混流、硬字幕烧录；全程 `try/except` 优雅降级不阻断主流程，结束统一释放临时文件；`VIDEO_TIMEOUT_SECS=600`（可 `MANJU_VIDEO_TIMEOUT` 覆盖）+ 30min 看门狗（OPS-04）互为兜底；`trace_id` 贯穿日志。TTS/BGM 依赖为可选，缺失则跳过。

### DONE-01 七项自证（§10 交付前自检）
交付前 MUST 逐条回答的七项：①需求覆盖 ②环境健康（7788/8099/反代均 200）③迁移落地（`PRAGMA table_info` 核验）④接口验证 ⑤能力验证（单元/集成测试证据）⑥回归测试（ui_flow/pipeline_e2e 全绿）⑦纪律自检（CLOSE/REDUN/LOG/OPS 落点，无静默吞错）。纪律优先级 CLOSE-04 资金最高；提交闸门「改动即更新 PROJECT_MAP」。

### 五阶段与导演调度 Agent 架构对齐设计（骨架阶段）
把 P1–P5 映射到手册四层架构（Layer0–3）与 DAG N01–N09、§6 错误码、§5 资产注入；当前为**骨架阶段**，已落地 Director Agent Core（`director/`：errors/dag/scheduler/agents 四子 Agent 契约+编排）、512 维人脸向量注入、首尾帧锚定实跑、N06 真实品控闭环（人脸相似度≥0.8）、看门狗退冻结金（CLOSE-04）。详见该原文。
