# 斗技图鉴梳理报告（2026-11-15）

> 用户：「我当前宗门这个很明显大部分都不是斗技，丹会都叫斗技？？？什么乱七八糟的，你重新梳理一遍」。
> 唯一数据源：`src/plugins/doupo/skill_book.py`；机器闸门：`tools/check_skill_catalog.py --check`。

## 1. 判定标准

`SKILL_BOOK` 只收录**战斗中可由个人施展、有施展流程与战斗效果**的技能（斗技/功法/秘法/身法/防御/血脉能力）。以下四类一律不是斗技：

| 类 | 例子 | 原著性质 |
|---|---|---|
| 炼药 / 丹方 / 考核 / 大会 / 表决 / 炼制流程 | 炼药术与丹方、炼药师品阶考核、丹会、小丹塔大长老院表决、药尘炼药术、天妖傀炼制秘法 | 炼药界事务与制度 |
| 组织制度 / 传承 / 进化 / 搜捕事务 | 花宗传承、五火传承、四派功法合流、吞噬血脉延续、七彩吞天蟒进化、灵魂体搜捕 | 剧情事件 |
| 护山大阵 / 体质 / 血脉族纹 / 异火本体 | 星陨阁大阵、护族大阵、联盟大阵、厄难毒体、萧族族纹、虚无吞炎 | 非个人施展的斗技 |
| 无具体技名的泛称 | 冰皇冰系斗技、毒属性功法、阴寒属性功法、寒冰屏障、隐身 | 描述词，不是技名 |

资料不丢：全部按宗门归档进 `FACTION_LORE` 与 `factions.py::lore`，宗门卡/文档仍可引用；但绝不进斗技池、四槽或战斗。
