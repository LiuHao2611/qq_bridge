# 贾维斯管家 · 对话测试口令表 v2（M1–M9 逐字对应源码）

> 用途：发给 QQ 机器人做真机对话测试。**全部子命令、别名、权限门均从 `__init__.py` 分发代码实抓**（2026-10-21，对应 master `b9faf43`），非凭记忆。
> 每条给出：精确语法、可复制口令、参数格式、预期反应、失败样例（失败样例也算验收点——**诚实报错**是设计目标，假成功才是 bug）。
>
> **通用规则**
> - 「主人」= 你的 QQ（`BOT_OWNER_QQ`）。标 🔒 的仅主人可用；标 👥 的所有人可用。
> - **群聊必须 @ 机器人**（2026-09-04 收紧：群消息不 @ 不响应）；**私聊直接发**。
> - 命令族路由全部 `startswith("/xx")`——**斜杠必须打全**，裸词（如「记忆」）不会进命令族，会落 AI 闲聊。
> - 高危操作有确认流：回「确认」执行（30 秒内有效），**发任何其它指令即取消**。
> - 每族末尾附**负面用例**（故意发错，验证拒绝路径是否诚实、清晰）。

> 前置：无。存储自动持久化。自然语言入口：每轮对话后自动提取（`memory_manager.ingest`），无需手动。

## M2 工具总线 · 提醒（`/提醒` 族 + 自然语言）👥

> 前置：无（提醒调度随插件常驻）。**时间解析只信 LLM**（`ReminderParser`，禁正则兜底）——解析失败会显式让你换个说法，绝不瞎猜。

| 口令 | 说明 |
|---|---|
| `/提醒 20分钟后 喝水` | 创建（时间整句交给 LLM 解析） |
| `/提醒 明早八点 叫我起床` | 创建（相对日期） |
| `/提醒 列表` | 别名 `看看` `list` `ls` `所有`——列本会话待触发提醒 |
| `/提醒 取消 2` | 别名 `删` `删除` `cancel` `del`——按序号取消（也接受内部编号如 `a1b2c3d4`） |
| `/提醒 改 2 明晚九点` | 别名 `修改` `modify` `mod`——改触发时间（可顺带改内容） |

**自然语言双轨**（无斜杠也能建）：`提醒我 3 分钟后喝水`、`半小时后提醒我关火`、`每天早上 9 点提醒我晨会`——走 AI 模式 Function Calling 的 `remind_create` 工具。

**负面用例**：
- `/提醒 啥时候来都行 喝水` → LLM 解析不出时间 → 应明确说「解析失败换个说法」，**不得**编一个时间。
- `/提醒 取消 99` → 应说不存在这条。

## 冒烟顺序（建议 15 分钟跑完）

1. **底座**：私聊 `电脑咋样` → 体检卡。群聊不 @ 发同句 → 无响应。
2. **M6 群聊边界（今天修的点，重点）**：群里 @机器人 发 `硬件温度` → 机器人告知「私聊才能用」，**不得否认主人身份**。
3. **M6 查询**：私聊 `/pc temp`（你机器上 CPU 温度应诚实提示装 LHM）、`/pc core`、`/pc net`、`/pc display`、`/pc proc explorer`。
4. **M6 确认流**：`/pc kill 无关紧要进程` → 回确认 → 回「确认」→ 执行；再试一次发别的指令 → 应提示已取消。
5. **M6 文件**：`/pc disk D:/AI` → 目录树；`/pc del` 一个测试文件 → 确认 → 去回收站找得到。
6. **M1 记忆**：`/记忆 我 职业=测试` → `/记忆` 可见 → `/记忆 忘记 职业`。
7. **M2 提醒**：`提醒我 1 分钟后说 hi` → 1 分钟后收到；`/提醒 列表` → `/提醒 取消 1`。
8. **M3 情感**：聊两句带情绪 → `/情感 心情` 看自动落点。
9. **M4**：发图 + `/看图`；`/看图 说 你好` → 收到语音。
10. **M5**：群内 `/风格 学` → `/风格 看`。
11. **M7**：`/dl 状态`（aria2 未起=诚实报错）。
12. **M9**：`/ops git` → `/ops 通知 测试`。
13. **M8**：`/ha 帮助`（无 HA=未配置提示，预期）。
14. **电源高危放最后**：`/pc power 重启` → 确认 → 5s 倒计时内发「取消」→ 应中止。

> 验收红线：任何**假成功 / 静默失败 / 黑屏截图 / 该报错却装没事**都算 bug，直接反馈。
