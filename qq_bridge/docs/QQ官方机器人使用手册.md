# QQ 官方机器人使用手册（/qq-official）

> 适用页面：`http://127.0.0.1:8099/qq-official`
> 后端命名空间：`/api/qqo/*`（与 NapCat 的 `/api/qq/*` 完全隔离）
> 最后核对：基于 `qq_bridge/src/plugins/qq_bridge/config_api.py` 与 `__init__.py` 源码

---

## 一、这是什么 / 和 NapCat 的关系

本页管理的是**第二个机器人——QQ 官方平台机器人**（独立 APPID 应用，不是某个挂机 QQ 号）。

它与「QQ 机器人」(/qq-bridge，NapCat 小号) 是**两个独立身份、两套接口、互不影响**：

| 维度 | 官方机器人（本页） | NapCat 小号（/qq-bridge） |
|---|---|---|
| 身份 | 开放平台 APPID 应用 | 真实 QQ 号 |
| 接口 | `/api/qqo/*` | `/api/qq/*` |
| 用户标识 | openid（映射成**负数** ID） | 真实 QQ 号（正数） |
| 是否免费 | 免费，合规官方接口 | 需挂机小号 |
| 掉线影响 | 不影响对方 | 不影响对方 |

**结论**：在本页改任何参数都不会动到 NapCat 的配置；`OFFICIAL_ENABLE=false` 时官方适配器一行都不注册，NapCat 零影响。两者不会冲突。

---

## 二、前置准备：在 QQ 开放平台创建机器人

1. 打开 [QQ 开放平台](https://q.qq.com/) → 创建机器人应用，拿到：
   - **AppID**
   - **AppSecret**
2. 在平台「开发 / 接入」里选择**私域 WebSocket 接入**（即本页 `OFFICIAL_USE_WEBSOCKET=true`，无需公网服务器）。
3. 在「事件订阅」里开启 **群 @消息 + 单聊（C2C）消息**、**群成员变动**（对应下面的 Intent）。
4. 在「服务范围」里把机器人拉进目标群，并**打开「允许机器人主动发言」**（出图结果走主动消息，必须开）。

## 三、配置（本页共 8 个参数）

本页「机器人配置」区动态渲染以下 8 项。带「核心」红标的 3 项（开关 / AppID / Secret / 接入方式）改完**必须重启 bridge（8080）**才生效；其余保存即热生效。

### 1. 启用官方通道 `OFFICIAL_ENABLE`（核心·bool）
- `true`：同一进程内同时跑 NapCat + 官方机器人。
- `false`：只跑 NapCat，官方适配器不注册。**关闭不影响 NapCat。**
- 改完需重启。

### 2. AppID `OFFICIAL_APPID`（核心·text）
- 开放平台创建机器人后获得。
- **必须和 Secret 同时填写**，bridge 启动时才会注册官方适配器。
- 改完需重启。

### 3. AppSecret `OFFICIAL_SECRET`（核心·text·密钥）
- 机器人密钥，**只写入 .env，本页不回显原值**（防泄露）。
- 改完需重启。

### 4. 沙箱环境 `OFFICIAL_SANDBOX`（bool）
- `true`：沙箱，不受消息频控，联调阶段建议开（官方 FAQ Q19）。
- 改完需重启。

### 5. WebSocket 接入 `OFFICIAL_USE_WEBSOCKET`（bool）
- `true`：bridge **主动连官方网关**，不需要公网服务器（推荐、本机即可）。
- `false`：走 Webhook，需要 **HTTPS 公网回调地址**。

### 6. 事件订阅 Intent `OFFICIAL_INTENT`（textarea·JSON）
默认值：
```json
{"c2c_group_at_messages": true, "group_members": true}
```
- `c2c_group_at_messages`：群 @ 与私聊消息（**生图能力的前提，必须 true**）。
- `group_members`：群成员变更（入群/新人欢迎用）。
- 改完需重启。

### 7. 单群每日主动消息上限 `OFFICIAL_DAILY_GROUP_LIMIT`（int）
- 平台硬限 **1000 条/群/天**，这里自限留余量（默认 900）。
- 出图慢时被动回复超时，会自动转主动消息并计数；超限自动降级为「提示去任务中心」，**不会撞 40034100 报错**。

### 8. 被动回复最长等待 `OFFICIAL_PASSIVE_MAX_AGE`（int）
- 默认 240 秒。超过则改走主动消息。
- 平台硬限：被动回复 **5 分钟内有效、每条用户消息最多回 5 次**，超时必转主动。

> 保存：改完点右上角「保存」。带「核心」的项会弹二次确认「修改核心参数 … 需重启」；保存成功提示「重启 QQ 机器人后生效」时，去重启 `qq_bridge`（8080）进程即可。

## 四、怎么用（用户侧怎么和机器人对话）

本页是**配置 / 状态页**，没有聊天框。真正的对话发生在 **QQ 客户端里**——用户 @机器人 或直接私聊机器人。

### 触发词（与 NapCat 共用同一套关键词，见 `DRAW_KEYWORDS`）
默认：`生图、画图、作画、生成图片、draw`
- 私聊 / 群 @ 时发送「**生图 一只在雨中的黑猫**」→ 文生图。
- 发送「**draw a cyberpunk city**」→ 文生图（英文也行）。

### 图生图（发图片）
- 在 QQ 里 **@机器人 + 发一张图**（或私聊发图），文字作为提示词 → 以该图为底图重绘。
- 适配器自动把图片段解析为输入图，`intent.route()` 检测到有图即走图生图（复用 NapCat 同一套逻辑）。

### 图片是怎么收发出来的
- **你发图**：QQ 客户端里真实发送一张图片，适配器解析成图片输入（不是任何文本指令）。
- **机器人回图**：生成的图由 `channel/official.py` 下载成字节，用官方 API **本地上传**发出去（`file_image(data, file_name="image.png")`）。`image.png` 只是默认文件名占位，**不需要你手敲**。
- **出图慢的兜底**：超过被动回复时效（5 分钟 / 每条 5 次）→ 自动转主动消息并计入上面第 7 项的日额度。

### 关于 `@image:image.png`
**这个字符串不是本系统的任何语法，在本项目代码里不存在，也不能在本页输入。**
- 本页只有状态 + 配置，没有输入框可以填它。
- 它可能是 OneBot 的 CQ 码 `[CQ:image,file=...]` 的误记；但官方机器人走官方 WebSocket 适配器，**只认真实消息里的图片段**，不解析任何 `@image:` / CQ 码文本。
- 想「让机器人用某张图」：直接在 QQ 里把那张图发给机器人即可，无需任何特殊前缀。

## 五、官方平台的客观限制（须知）

1. **拿不到用户 QQ 号**：只有 openid。所以按 QQ 号配置的白/黑名单对官方机器人无效——访问控制靠平台「服务范围」+ 群主邀请。
2. **机器人不能主动加群**：需群主把机器人拉进群；出图走主动消息，群主需开「允许机器人主动发言」。
3. **消息不能含未配置 URL**：含任意外链会报 `40054010`，视频等链接会改为「去任务中心查看」提示。
4. **主动消息限频**：60 条/分钟（机器人全局）、单群 20 条/分钟、**1000 条/群/天**。
5. **被动回复仅 5 分钟内有效、每条用户消息最多回 5 次**，超时自动转主动消息并计频。

## 六、状态页怎么看

「运行状态」区：
- **机器人 ID**：注册成功后的机器人 ID（openid 派生）。
- **环境**：沙箱（不受频控）/ 正式。
- **单群每日主动消息上限 / 今日已用**：第 7 项与实时计数。
- 离线 / 未启用 / 缺 AppID·Secret 会有对应徽标；`bridge(8080) 不可达` 说明 qq_bridge 服务没在跑（NapCat 页不受影响）。

## 七、最小上手流程

1. QQ 开放平台创建机器人，拿到 AppID / AppSecret。
2. 开放平台开启「私域 WebSocket 接入」+「群 @ 与单聊消息」事件。
3. 本页填写：`OFFICIAL_ENABLE=true`、`OFFICIAL_APPID=...`、`OFFICIAL_SECRET=...`，`OFFICIAL_USE_WEBSOCKET=true`，`OFFICIAL_INTENT` 保持默认。
4. **重启 qq_bridge（8080）** 让核心参数生效。
5. 群主把机器人拉进群并开「允许主动发言」。
6. 在 QQ 里 `@机器人 生图 一只猫` 验证出图；发一张图验证图生图。

## 八、常见问题

**Q：改了 AppID/Secret 没反应？**
核心参数要重启 8080 才生效；检查状态页「凭据已配置 / 在线」徽标。

**Q：群里 @机器人 没回复？**
确认开放平台「事件订阅」已开 `c2c_group_at_messages`；机器人已被拉进群；Intent 已正确配置且已重启生效。

**Q：出图慢 / 没反应？**
官方被动回复 5 分钟超时后会转主动消息（需群主开「允许主动发言」）。出图本身依赖主项目 7788 的生图能力，看 7788 日志。

**Q：和 NapCat 会抢消息 / 冲突吗？**
不会。两套 matcher、两套接口、两套用户标识（openid 负数 vs QQ 号正数），逻辑完全隔离。

**Q：`@image:image.png` 在哪填？**
不需要、也不能填。发图直接在 QQ 客户端发真实图片即可。
