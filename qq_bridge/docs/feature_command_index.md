# 贾维斯管家 · 功能清单与口令索引（M1–M9 + 人设 + AI 模式）

> 功能 → 口令 → 说明 的总索引。命令全部从源码实抓（同 `test_commands_sheet.md`），非凭记忆。
> 凡标 🔒 = 仅主人；👥 = 群聊/私聊均可（群聊须 `@` 机器人，裸词不进命令族）。
> 完整语法/参数/负面用例见 `test_commands_sheet.md`；智能家居 HA 对接见 `smarthome_ha_setup.md`。

---

## 一、通用规则（适用全部命令族）

- 「主人」= 你的 QQ（`BOT_OWNER_QQ`）。🔒 仅主人；👥 所有人。
- **群聊必须 @ 机器人**；私聊直接发。命令族路由全部 `startswith("/xx")`，**斜杠要打全**，裸词（如「记忆」）会落 AI 闲聊而非命令。
- 高危操作走确认流：回「确认｜确认执行｜y｜yes」执行（30 秒有效）；发其它指令即取消。
- 失败一律**诚实报错**，假成功才是 bug。

**告警推送目标**（`OPS_NOTIFY_TARGET`，复用 M9）：纯数字=**私聊**；`-987654`/`g987654`=**群**。
